# WARRIORS Abyss 한국어 오역 수정 패치

**WARRIORS Abyss** (PC, Ultimate Edition)의 공식 한국어 번역 중 일본어 원문과 뜻이 다르거나 수치가 잘못 표시되는 문장을 원문에 맞게 고치는 **비공식 팬 패치**입니다.

## 다운로드

[**Releases**](../../releases/latest)에서 `WARRIORS_Abyss_KoFix_v*.zip`을 받으세요.

## 수정 내용 (v1.0, 224곳)

| 대상 | 곳 | 예시 |
|---|---|---|
| 무기·특성·유보·염마장·망자의 기억 효과 설명 | 210 | 조운(어나더) 광룡신창: "속성 계열 증표 1개당…" → "증표 「속」 1개당 공격력 및 민첩 +2%" |
| 소환기 효과 설명 | 7 | 연금술・화＋빙: "뇌속성과 화속성 탄" → "염속성과 빙속성 탄" |
| 비어 있던 시스템·미션·옵션 메시지 | 7 | 아이템 개봉, DLC 안내, 키 중복 할당 경고 등 |

- 수치·피눈물 값이 표시되지 않던 문장, +/- 부호가 반대인 문장, "회피 후"가 "회복"으로 번역된 문장 등을 고쳤습니다.
- 용어(영걸, 증표, 피눈물 등)와 고유명사·이름은 공식 번역을 그대로 따릅니다.
- 전체 목록: [KoPatch/수정목록.txt](KoPatch/수정목록.txt)

## 사용 방법

1. 게임을 완전히 종료합니다.
2. `WARRIORS_Abyss_KoFix.exe`를 게임 폴더(`WARRIORS Abyss.exe`가 있는 폴더)에 넣고 실행합니다.
3. **1. 패치 적용**을 선택합니다.

되돌릴 때는 같은 프로그램에서 **2. 원래 번역으로 복구**를 선택합니다 (패치 시 만든 `*.kofix_backup`으로 복구).

## 패치 완전 삭제

패치는 게임 폴더에 프로그램과 백업 파일 말고는 아무것도 설치하지 않습니다. 아래 순서대로 하면 흔적 없이 지워집니다.

1. 게임을 완전히 종료합니다.
2. `WARRIORS_Abyss_KoFix.exe`를 실행하고 **2. 원래 번역으로 복구**를 선택합니다.
   - `WARRIORSAbyss\LINKDATA_HAN.BIN` / `.IDX`가 패치 전 파일로 되돌아갑니다.
   - 백업 파일(`LINKDATA_HAN.BIN.kofix_backup`, `LINKDATA_HAN.IDX.kofix_backup`)은 복구가 끝나면 자동으로 삭제됩니다.
3. `WARRIORS_Abyss_KoFix.exe`를 삭제합니다.

**백업 파일을 지웠거나 복구가 안 될 때**

- Steam: 라이브러리에서 게임 우클릭 → **속성** → **설치된 파일** → **게임 파일 무결성 검사**를 실행하면 `LINKDATA_HAN` 원본을 다시 받습니다.
- 그 뒤 `WARRIORSAbyss` 폴더에 `*.kofix_backup` 또는 `*.tmp` 파일이 남아 있으면 지워도 됩니다.

레지스트리, 설정 파일, 다른 폴더에는 아무것도 만들지 않습니다.

## 안내

- 바뀌는 파일은 `WARRIORSAbyss\LINKDATA_HAN.BIN` / `.IDX` 두 개뿐입니다.
- 문장마다 원래 번역이 예상과 같은지 확인한 뒤에만 바꿉니다. 게임 업데이트로 문장이 달라졌으면 그 문장은 건너뜁니다.
- 여러 번 실행해도 안전합니다. 게임 업데이트나 파일 무결성 검사 뒤에는 다시 실행하세요.
- 서명되지 않은 프로그램이라 Windows SmartScreen 경고가 나올 수 있습니다 ("추가 정보" → "실행").

## 구성

| 경로 | 내용 |
|---|---|
| `KoPatch/` | 패치 프로그램 (C#, .NET 9). `patch.tsv`에 수정 데이터가 들어 있고 실행 파일에 포함됨 |
| `fixes/`, `fixes_multi/` | 텍스트 섹터별 수정 목록 (`행 번호` 또는 `행.열` ⇥ 새 번역, `\e` = 서식 태그, `\n` = 줄바꿈) |
| `LinkTool/` | LINKDATA 아카이브 풀기/묶기, 텍스트 덤프·비교 도구 |
| `txt2.py`, `txtpatch.py`, `txtall.py` | 텍스트 테이블 읽기·패치·일본어 원문 비교 |
| `mkpatchdata.py`, `mkdist.py`, `release.ps1` | 배포 파일 만들기 |
| `build.ps1`, `install.ps1` | 개발용: 직접 빌드해서 게임에 설치/복구 |

### 직접 빌드하기

필요: .NET 9 SDK, Python 3 (환경 변수 `KOFIX_PYTHON`으로 경로 지정 가능)

1. `LinkTool`을 빌드합니다: `dotnet build LinkTool -c Release -o bin`
2. 게임의 `LINKDATA_HAN.BIN/.IDX` 원본을 `backup/`에 복사하고 `bin\LinkTool.exe extract backup\LINKDATA_HAN han`으로 풉니다.
3. `pwsh -File release.ps1` → `dist/`에 배포 zip이 만들어집니다.

## 기술 메모

- `LINKDATA_*.IDX`: 항목당 32바이트 (u64 오프셋, u64 크기, u64 저장 크기, u64 압축 여부)
- 압축 항목: 0x10000 단위 청크 zlib, 0x80 정렬
- 텍스트 테이블: `u32 개수, u32 문자열 영역 크기, u64 0, 항목[개수], 문자열`. 항목 크기는 8~20바이트이고, 한 항목에 문자열이 여러 개(이름+설명 등) 들어 있는 테이블도 있음 (각 u32 필드 위치 기준 상대 오프셋)
- 서식 태그: `ESC`+2글자 (`C?` 색상, `U?` 아이콘, `S?` 변수 번호, `P?` 버튼), `ESC R` 서식 해제

## 면책

- KOEI TECMO GAMES와 관계없는 비공식 팬 패치입니다. 게임의 저작권은 KOEI TECMO GAMES에 있습니다.
- 이 저장소와 배포 파일에는 게임 데이터가 들어 있지 않습니다. 수정할 문장과 패치 도구만 들어 있습니다.
- 사용에 따른 문제는 사용자 책임입니다. 패치 전 원본 백업이 자동으로 만들어집니다.
